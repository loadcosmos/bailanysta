# Bailanysta

Bailanysta — мобильная социальная сеть, где люди делятся «сигналами роста»: инсайтами, вопросами, прогрессом и полезными ресурсами в темах науки, AI, здоровья, карьеры и бизнеса.

Один проект на Expo работает на iOS, Android и в web. Без входа можно смотреть ленту и искать; после регистрации — публиковать, лайкать, комментировать и подписываться.

**Live:** https://bailanysta-ruby.vercel.app  
**GitHub:** https://github.com/loadcosmos/bailanysta

## Что реализовано

- профиль и создание постов прямо из профиля;
- лента с автором и текстом, фильтр по темам;
- регистрация и вход по email/паролю, восстановление пароля;
- вход через Google;
- поиск по тексту, автору, теме и тегам;
- лайки, комментарии, подписки, уведомления;
- редактирование и удаление своих постов;
- светлая и тёмная тема, русский и казахский язык;
- skeleton-загрузка и пустые состояния;
- админ-панель для модерации;
- AI-помощник для черновика поста (бонус);
- серверный API — клиент не ходит в Supabase напрямую.

## Стек и почему он

| Технология | Зачем |
|---|---|
| **Expo + React Native** | Один UI для мобилки и web, быстрый старт без Xcode/Android Studio на каждый экран |
| **TypeScript** | Меньше ошибок в данных постов, профилей и API |
| **Supabase** | Готовая auth + Postgres + RLS без своего бэкенда с нуля |
| **Vercel Functions** | Простой `/api`-слой, ключи остаются на сервере |
| **Playwright** | Проверка основных сценариев в браузере |

## Установка и запуск

Нужен Node.js 22+.

```bash
git clone https://github.com/loadcosmos/bailanysta.git
cd bailanysta
npm install
npx expo start
```

Без `.env` приложение открывается в **demo mode** с тестовой лентой. Нажми `w` для web, `i` / `a` для симуляторов.

Проверки:

```bash
npm test
npm run typecheck
npm run lint
npm run e2e
```

## Подключение Supabase

1. Создай проект на [supabase.com](https://supabase.com).
2. Выполни SQL из [`supabase/schema.sql`](supabase/schema.sql).
3. Скопируй `.env.example` → `.env.local`, заполни ключи.
4. На Vercel добавь `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SECRET_KEY`, `AUTH_PUBLIC_URL`.
5. Для AI (бонус): `GEMINI_API_KEY` в Vercel — только server-side.
6. В Supabase Auth добавь redirect URL: `https://<твой-домен>/api/auth/google/callback`.
7. Первого админа назначь: `node scripts/promote-admin.mjs you@example.com`

## Процесс разработки

Сначала сделал экраны и навигацию с demo-данными, чтобы быстро проверить UI. Потом подключил Supabase и вынес все запросы в `/api` на Vercel. Auth делал поэтапно: email → Google OAuth → автосоздание профиля. Социальные фичи (лайки, комменты, подписки) добавлял после того, как заработали посты и лента.

Дизайн брал из референса: cyan-акценты, крупная типографика, фото-карточки, плавающая нижняя панель. Проверял в основном в мобильном Chrome (393px).

## Уникальные решения

1. **Сигнал вместо поста** — у публикации есть тип (инсайт, вопрос, прогресс, ресурс), чтобы лента была понятнее.
2. **Demo mode** — приложение работает без ключей, удобно для проверки UI до деплоя.
3. **AI только как черновик** — модель предлагает текст, пользователь сам нажимает «Применить» и публикует.

## Компромиссы

- Загрузка картинок не сделана — в схеме есть `image_url`, но Storage не подключал.
- Push-уведомлений нет — только in-app.
- Лента без сложных SQL-view; для учебного проекта проще читать код.
- Google OAuth и AI требуют настройки ключей на стороне Supabase/Google.

## Известные проблемы

- Без env web работает в demo mode — это ожидаемо.
- Supabase «Leaked password protection» доступна только на Pro-плане.
- EAS-сборки требуют личный Expo/Apple/Google аккаунт.
- AI зависит от Gemini API; без ключа кнопка показывает «временно недоступен».

## Deploy

Web деплоится на Vercel (`vercel.json`, команда `npm run export:web`). Секреты — только в переменных Vercel, не в Git.
